# ZPU (zpu.lol)

Official personal portfolio & profile website for **ZPU (xZPUHigh)**.
Live at **[zpu.lol](https://zpu.lol)**.

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **UI:** React 19 + Tailwind CSS 4
- **Language:** TypeScript
- **Hosting:** Vercel

## Dev Loop
```bash
npm install
npm run dev
```
